## Как открыть игру по ссылке (GitHub Pages)

1. Залей изменения: `git push` в ветку `main`.
2. На GitHub: **Settings** → **Pages** (слева внизу в меню репозитория).
3. В блоке **Build and deployment** выбери источник: **GitHub Actions** (не «Deploy from a branch», если настроен workflow из `.github/workflows/`).
4. Подожди 1–2 минуты после пуша. Вкладка **Actions** должна показать зелёный запуск **Deploy to GitHub Pages**.
5. Игра будет по адресу:  
   `https://<твой-ник>.github.io/IGRA_DROBI/`

Если пункта **Pages** в Settings нет: проверь, что у тебя есть права на репо (ты владелец или collaborator).  
Для **приватного** репозитория бесплатный GitHub Pages может быть недоступен — сделай репо **public** или смотри правила плана в [документации GitHub](https://docs.github.com/pages).
